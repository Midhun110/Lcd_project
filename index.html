Even Parity Rule

Even Parity requires the total count of 1s in the transmission frame (data + parity) to be an even number. If data has an odd number of 1s, parity is set to 1.

XOR Truth Verification

0 ⊕ 0 ⊕ 0 ⊕ 0 = 0. Since calculated parity 0 equals received parity 0, the transmission frame is free of single-bit errors.
